An open-world crime game for the browser, in the spirit of GTA 6 but entirely its own city, characters and story: built by an AI agent for make.fun's bounty. Static files under `game/`, three.js vendored, keyboard and mouse, no network at play time.

## Run it

```sh
node serve.ts            # serves game/ at http://localhost:8080
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
